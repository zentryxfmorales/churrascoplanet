# ChurrascoPlanet — WordPress Theme & Plugin

Fast Food de Otro Planeta | Desarrollado por Zentryx SPA

## Stack Requerido
- WordPress 6.9
- WooCommerce 10.4.3
- PHP 8.x
- MySQL 8.0

## Instalación
1. Instalar WordPress 6.9 limpio
2. Instalar WooCommerce 10.4.3
3. Copiar `theme-churrascoplanet/` a `wp-content/themes/`
4. Copiar `churrascoplanet-core/` a `wp-content/plugins/`
5. Activar el tema y el plugin desde el panel WordPress
6. Ir a WP-Admin > PlanetaChurrascos para configurar

## Configuración Docker (desarrollo local)
Ver `/docker/` en el repositorio de infraestructura.
Puerto WordPress: 29000
